## 1. Теоретична частина

### 1.1 Поняття CDI, HQ та CR

**CDI (Chronic Daily Intake)** — хронічне щоденне надходження забруднювача в організм людини. Це середня доза забруднювача, яку людина отримує щодня протягом тривалого періоду. CDI виражається в мг/(кг·день) і розраховується за формулою:

\[
CDI = \frac{C \cdot IR \cdot EF \cdot ED}{BW \cdot AT}
\]

де:

- **C** — концентрація забруднювача в середовищі (мг/л для води або мг/м³ для повітря)
- **IR** — інтенсивність надходження (л/день для води або м³/день для повітря)
- **EF** — частота впливу (днів/рік)
- **ED** — тривалість впливу (років)
- **BW** — маса тіла (кг)
- **AT** — час усереднення (днів)

**HQ (Hazard Quotient)** — коефіцієнт небезпеки, який використовується для оцінки неканцерогенного ризику. Він показує співвідношення між фактичним надходженням забруднювача та референтною дозою:

\[
HQ = \frac{CDI}{RfD}
\]

де:

- **RfD** — референтна доза (мг/(кг·день)) — максимальна доза, яка не викликає шкідливих ефектів при щоденному впливі протягом життя.

Інтерпретація HQ:

- HQ < 1 — ризик низький (прийнятний)
- 1 ≤ HQ < 4 — ризик помірний
- HQ ≥ 4 — ризик високий

**CR (Cancer Risk)** — канцерогенний ризик, який оцінює ймовірність виникнення раку в результаті впливу канцерогенних речовин:

\[
CR = CDI \cdot SF
\]

де:

- **SF** — фактор канцерогенного ризику ((мг/(кг·день))⁻¹) — коефіцієнт, що характеризує канцерогенну потенцію речовини.

Інтерпретація CR:

- CR < 10⁻⁶ — ризик дуже низький
- 10⁻⁶ ≤ CR ≤ 10⁻⁴ — ризик прийнятний/помірний
- CR > 10⁻⁴ — ризик високий

### 1.2 Опис параметрів

**C (Концентрація)** — кількість забруднювача в одиниці об'єму середовища. Для води вимірюється в мг/л, для повітря — в мг/м³.

**IR (Intake Rate)** — об'єм середовища, який людина споживає щодня. Типові значення: для води — 0.5–3 л/день, для повітря — 5–25 м³/день.

**EF (Exposure Frequency)** — кількість днів на рік, протягом яких відбувається вплив. Може коливатися від 30 до 365 днів/рік.

**ED (Exposure Duration)** — загальна тривалість впливу в роках. Зазвичай становить 1–30 років.

**BW (Body Weight)** — маса тіла людини в кілограмах. Типові значення: 15–100 кг.

**AT (Averaging Time)** — час усереднення для обчислення середньої дози:

- Для неканцерогенного ризику: AT = ED × 365 днів
- Для канцерогенного ризику: AT = 70 × 365 = 25550 днів (середня тривалість життя)

**RfD (Reference Dose)** — референтна доза, максимальна доза забруднювача, яка не викликає шкідливих ефектів при щоденному впливі протягом життя. Типові значення: 0.0001–0.1 мг/(кг·день).

**SF (Slope Factor)** — фактор канцерогенного ризику, який характеризує канцерогенну потенцію речовини. Якщо SF = 0, речовина не є канцерогенною. Типові значення для канцерогенів: 0.1–2 (мг/(кг·день))⁻¹.

## 2. Опис реалізації

### 2.1 Архітектура MERN

Проєкт реалізовано у стеку MERN (MongoDB, Express, React, Node.js). У даній роботі MongoDB не використовується, оскільки не потрібне зберігання даних — система виконує розрахунки в реальному часі.

**Структура проєкту:**

```
D:\burunduk\univer\ek\laba_3\
  server\
    app.js                 # Express сервер
    modules\
      healthRisk\
        compute.js         # Математична модель
        router.js          # API маршрути
        seed.js            # Генерація синтетичних даних
        compute.test.js    # Unit тести
  client\
    src\
      modules\
        healthRisk\
          api.js           # API клієнт
          Form.jsx         # Форма введення
          ResultCard.jsx   # Відображення результатів
          synthetic.js     # Генерація синтетичних даних
```

### 2.2 Серверна частина (Node.js/Express)

**app.js** — головний файл сервера, який налаштовує Express, підключає CORS для роботи з React-клієнтом, та реєструє маршрути для модуля healthRisk.

**compute.js** — містить чисту функцію `compute(payload)`, яка:

- Валідує вхідні параметри (перевірка на додатні числа, валідність medium)
- Обчислює AT залежно від типу ризику (канцерогенний/неканцерогенний)
- Розраховує CDI, HQ та CR за формулами
- Визначає рівні ризику (riskLevelHQ, riskLevelCR)
- Повертає нормалізовані вхідні дані, результати та метадані

**router.js** — реалізує POST маршрут `/api/healthRisk/calc`, який:

- Приймає JSON payload з параметрами
- Викликає функцію `compute()`
- Повертає результати або помилку 400 з описом

**seed.js** — містить функцію `genSynthetic()`, яка генерує реалістичні тестові дані:

- C: 0.001–5
- IR: 0.5–3 (вода) або 5–25 (повітря)
- EF: 30–365
- ED: 1–30
- BW: 15–100
- RfD: 0.0001–0.1
- SF: 0 або 0.1–2
- medium: випадково "water" або "air"

**compute.test.js** — Jest тести, які перевіряють:

- Коректність обчислення CDI, HQ, CR
- Обробку помилок для невалідних даних
- Коректність визначення рівнів ризику

### 2.3 Клієнтська частина (React)

**api.js** — містить функцію `calcHealthRisk(payload)`, яка виконує POST запит до сервера та обробляє відповіді/помилки.

**synthetic.js** — портована версія `genSynthetic()` з сервера для генерації синтетичних даних на фронтенді.

**Form.jsx** — React компонент форми, який:

- Містить поля для всіх параметрів (medium, C, IR, EF, ED, BW, RfD, SF)
- Має кнопку "Згенерувати синтетичні дані" для заповнення форми
- Має кнопку "Обчислити" для відправки запиту
- Відображає помилки червоним кольором
- Показує `ResultCard` після успішного обчислення

**ResultCard.jsx** — компонент для відображення результатів:

- Показує нормалізовані вхідні параметри
- Відображає CDI, HQ, CR з одиницями виміру
- Показує рівні ризику з кольоровою індикацією
- Містить інтерпретацію результатів
- Використовує grid layout для красивого відображення

### 2.4 Особливості реалізації

1. **Валідація даних**: Всі числові параметри перевіряються на додатність, medium — на валідність значень.

2. **Автоматичне обчислення AT**: Час усереднення обчислюється автоматично залежно від типу ризику (канцерогенний/неканцерогенний).

3. **Обробка помилок**: Сервер повертає статус 400 з описом помилки, клієнт відображає її користувачу.

4. **Синтетичні дані**: Можливість швидко заповнити форму реалістичними тестовими даними.

5. **Тестування**: Unit тести забезпечують коректність математичних обчислень.

## 3. Висновки

У ході виконання лабораторної роботи було реалізовано систему оцінки ризику для здоров'я населення від забруднювача у стеку MERN. Система дозволяє:

1. **Обчислювати ризики** на основі вхідних параметрів за стандартними формулами CDI, HQ та CR.

2. **Оцінювати рівні ризику** для неканцерогенних (HQ) та канцерогенних (CR) забруднювачів з автоматичною інтерпретацією результатів.

3. **Генерувати тестові дані** для швидкого тестування системи.

4. **Валідувати вхідні дані** з наданням зрозумілих повідомлень про помилки.

Система має модульну архітектуру, що дозволяє легко розширювати функціональність. Серверна частина містить чисті функції, які легко тестувати, а клієнтська частина надає зручний інтерфейс для введення даних та перегляду результатів.

Реалізація відповідає вимогам технічного завдання та забезпечує коректне обчислення ризиків згідно з математичними моделями.
